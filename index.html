Everything a team needs to run on multiple models.

多模型接入所需的一切，开箱即用。

Each provider has its own account, billing and API format. Code Flow replaces that overhead with a single integration and a single bill.

每家模型厂商都有各自的账号、计费和接口格式。Code Flow 用一次集成、一份账单取代这些重复成本。

Unified endpoint统一端点

Call every supported model with the same request format. Switching models is a one-field change.

所有模型使用同一种请求格式，切换模型只需修改一个字段。

Transparent pricing透明定价

Per-model prices are published in the model marketplace before you spend anything.

模型市场公开列出每个模型的价格，消费之前即可确认成本。

Usage and cost logs调用与费用记录

Every call is recorded with its model and cost, so spend can be traced back to the request.

每次调用都记录所用模型与费用，支出可追溯到具体请求。

Key management密钥管理

Issue separate API keys per project and revoke any of them at any time.

按项目创建独立的 API 密钥，可随时停用。

Prepaid top-up预付充值

Balance is funded in advance with redemption codes, so cost never runs ahead of budget.

通过兑换码预先充值余额，费用始终在预算之内。

Partner program合作伙伴计划

Built-in invite and earn tools for the resellers and partners who bring teams onto the platform.

内置邀请返利机制，支持分销商与合作伙伴拓展客户。

Engineered to keep requests flowing.

为请求不中断而设计。

  • Weighted multi-channel routing多渠道加权路由 Each model is served through upstream channels with their own priority and weight, so traffic can be balanced or moved without any change on the client. 每个模型由多个上游渠道提供服务，各渠道可设置优先级与权重，流量调度无需客户端做任何改动。
  • Channel health checks渠道健康检测 Channels are tested from the console and tracked by response time. A degraded channel is taken out of rotation in one click. 在控制台即可测试各渠道并查看响应时间，异常渠道可一键下线。
  • Regional hosting区域节点 Served from Tokyo over HTTPS, close to the teams the platform was built for. 部署于东京节点，全程 HTTPS，贴近平台所服务的用户群体。
  • Groups and roles分组与权限 User groups and roles keep customers, partners and administrators separate. 通过用户分组与角色，区分客户、合作伙伴与管理员。

A console built for operating at scale.

为规模化运营打造的控制台。

The same console serves developers managing keys and spend, and operators managing channels, pricing and accounts.

同一套控制台，既供开发者管理密钥与支出，也供运营者管理渠道、定价与账户。

Integrate by changing two lines.

改两行配置，即可完成接入。

Code Flow accepts the OpenAI request format. Point an existing client at the Code Flow base URL, swap in a Code Flow key, and choose a model.

Code Flow 兼容 OpenAI 请求格式。将现有客户端的 base URL 指向 Code Flow，换上 Code Flow 密钥，再选择模型即可。

# one request shape for every model
curl https://codeflowapi.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_KEY" \
  -d '{ "model": "choose-a-model",
        "messages": [ ... ] }'
